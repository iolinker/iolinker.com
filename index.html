02 / MAKE IT YOURS

不是更多窗口，
而是更完整的执行路径。

围绕已有工具与数据组织任务，从个人助手到重复执行的业务流程。外部能力需要对应服务、凭证与授权。

01 / SCHEDULE

把重复任务交给时间。

为 Agent 创建定时任务，查看启停状态、执行记录与关联会话。确定的节点路径也可以使用工作流 Crontab。

定时任务指南 →
02 / EXTEND

接入熟悉的工具与知识。

用技能组织任务方法，用 MCP 连接工具，用知识库提供参考资料。按 Agent 选择能力，而不是默认开放一切。

技能与工具指南 →
03 / DATA

让数据进入工作流。

创建数据表、配置字段、筛选和导入记录。通过流程节点查询、插入、更新或删除数据，连接采集与后续处理。

数据表指南 →
04 / OBSERVE

结果之外，也看见过程。

检查工作流执行记录、版本变化和相关 Agent 链路。失败执行可从对应入口进行 AI 诊断，再回到画布修正。

运行与排障指南 →
